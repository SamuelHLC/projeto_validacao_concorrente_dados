# projeto_validacao_concorrente_dados
Projeto para aula de quarta feira 

# Validação Concorrente de Integridade de Dados

**Objetivo:** Demonstrar o ganho de eficiência (Speedup) através do processamento paralelo na validação de grandes volumes de dados entre bases SQL.

**Contexto:** O projeto simula um cenário real de migração de banco de dados onde a integridade precisa ser verificada em tempo recorde utilizando threads em Python.
